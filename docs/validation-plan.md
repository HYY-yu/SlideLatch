# 用户验证计划

状态：待执行；更新：2026-10-31。

## 验证问题

- 谁近期反复更新同一设计的 PPT？当前流程、耗时与替代方案是什么？
- 用户愿意自行配置模板，还是需要代配置？
- 原设计保留、错误检查与独立导出，哪些影响购买？
- 再次生成节省的时间能否覆盖配置与维护成本？

## 实验流程

### 1. 招募页与演示

建议投入 2–3 个工作日，先选一个窄人群和一种市场语言。主 CTA：**申请模板试用 / Apply for an early template trial**。

材料包括产品流程、早期试用说明、交互原型和两组不同内容的真实生成案例。原型标注模拟环节；案例先核对现有 DSL 的模板限制。

表单收集联系方式、PPT 类型与频率、最费时的环节、访谈与脱敏模板意愿。说明联系用途，营销订阅单独选择；模板在试点阶段收取。

### 2. 事实访谈

有合格报名即开始访谈：

- 最近一次报告为谁制作，模板多久复用一次？
- 从新内容到交付各花多久，如何修稿？
- 用过哪些软件、脚本或外包，为什么保留或放弃？
- 谁维护模板、谁使用、谁决定购买？
- 能否安排一次自己的模板试用？

记录真实任务、时间与授权范围，联系明细受控存储。

### 3. 人工辅助试点与收费

接入脱敏模板，用两组新内容生成 PPT，向用户说明人工协助方式。分别记录配置、协助、生成和修订耗时，以及支持对象比例与技术缺口。

试点后提出具体的接入服务、交付范围和价格，分别记录口头意愿、采购行动与付款。

## 观察指标

| 阶段 | 记录 | 首轮参考目标 |
| --- | --- | --- |
| 触达 | 渠道、市场/语言、有效访问、费用 | 记录转化分母与获客成本 |
| 报名 | 符合画像的联系人 | 约 10 个 |
| 访谈 | 最近真实任务与当前成本 | 约 5 次 |
| 模板 | 经授权的脱敏输入 | 约 3 份 |
| 重复使用 | 再次生成、协助与修订耗时 | 约 2 个用户/团队 |
| 购买 | 明确方案及付费行动 | 至少 1 个 |

目标用于组织实验，可随实际证据调整。当前尚无 SlideLatch 报名、使用或付款数据。

## 结果与行动

| 观察 | 行动 |
| --- | --- |
| 提供模板、再次使用并付费 | 收敛高频对象与问题，推进对应 MVP |
| 留资多，访谈或试用少 | 调整画像、承诺或渠道 |
| 希望代做，不愿配置 | 评估模板接入服务 |
| 接入与修复成本过高 | 缩小支持范围或调整客户群，补技术实验 |
| 独立合同不影响购买 | 下调可迁移性优先级 |
