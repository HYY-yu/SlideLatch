### Radar后续接入：只报告，不执行

现有登录会话可继续只读查看供应商后台；可以使用已授权PostHog连接按项目170688、app=slidelatch、environment=production做聚合，无需新建PostHog项目或扩大该连接权限。它不等于Radar项目10已有持久集成。

Radar `siteanalytics.Save`对新项目/provider连接要求read API token；空token只保留同项目同provider的既有秘密。加密Binding绑定项目/provider，没有支持把项目5的加密配置直接映射到项目10的免费账户复用接口。若现有用户持有的只读token已覆盖该PostHog项目或Slidelatch Cloudflare zone，可能无需创建新token/扩权，但仍需用户明确授权在项目10保存该既有token；本轮未读取或复制它。

Cloudflare后续步骤：核对现有token是否已有Slidelatch zone analytics只读范围→获准为项目10保存zone/token绑定→手动同步并检查domain隔离。现有token是否覆盖该zone未核验，不推定拥有权限。

PostHog还存在功能口径缺口：Radar默认按`event='$pageview'`和hostname统计，仅对Duck Rush有`page_view`特例；Slidelatch用`landing_viewed`并关闭自动pageview。因此不能仅保存app筛选就声称面板接好。后续应先为Slidelatch增加明确事件合同与测试，再保存项目10的现有授权token/API origin/project_id及app/environment筛选，聚合与后台核对。不能将无行结果当零访问。

GSC已有域名所有权可继续浏览器只读查；Radar OAuth令牌与项目绑定，新建项目10连接需要单独OAuth授权流程，没有直接复用项目5令牌的受支持路径。当前不执行OAuth、凭据复制或持久接入。sitemap提交也尚未执行，须按后续明确授权操作。
