# 纯前端 PPTX 标记工作台

更新：2026-10-31。首版验收模板：JoyfulWords 极简商务 v4，33 页。

## 功能边界

- 左侧 33 页独立 SVG 缩略图，中间 SVG 画布，右侧对象树与标记面板。
- 文本节点内容可编辑，作为 AI 理解填充数据的语义提示；字体、颜色、图片内容和样式只读，标签、位置、宽高可修改。
- 标记仅支持现有 DSL 类型，无自定义标签或标签原文编辑框。节点内容默认去重（支持尾部截断），允许编辑；输入实时更新画布，失焦保存到内存补丁，支持撤销/重做和重置。
- 文本最少/最多使用数字输入框与减/加按钮，从 0 起、不设业务最大值；每次增减 1，支持直接输入及键盘上下箭头。调节时按词组截取或循环填充画布与缩略图，字数预览不写入正文；用户编辑的节点内容写回原生文本，DSL 范围通过应用标记写回。
- 文本范围、图片编号、图标、序号位数、列表 ID/Item/数量范围、表格、图表及背景标签使用原 PPT-DSL。
- 可选择 Group 和子对象；画布拖动、右下角缩放手柄、撤销/重做、重置位置和重置所有操作。
- 文件在浏览器解析并打包，下载修改后的真实 PPTX。没有上传接口、业务服务器、第三方模型或遥测请求。
- 上传仍禁用；首版只开放极简商务。状态保存在组件内存，刷新恢复原稿。

## 数据链路

```text
原始 PPTX → pptxtojson → SVG 渲染
    ↓                         ↓
原始 OOXML 对象索引 ← 标签与布局补丁
    ↓
按 slidePath + shapeId 定位写回 → 浏览器重新读取核对 → Blob 下载
```

原始文件保留为权威来源，JSON 负责显示。补丁修改 `p:cNvPr/@name`、显式编辑的节点文本和对象已有 transform 中的 `off/ext`；原生表格缩放时同步按比例调整列宽与行高。Group 的 `chOff/chExt`、旋转翻转、未编辑文本、媒体、关系、备注、母版、图表和内嵌工作簿保持原稿。

内部布局统一使用 pt，写回按 `1 pt = 12700 EMU` 转换。组合使用父级矩阵和子坐标系，拖动及缩放时转换回原坐标。继承布局但没有自身几何的对象首版只开放标签修改。

## 错误与可观测性

- Debug：补丁对应页、shapeId、修改字段名，不记录用户正文。
- Info：解析、写回开始与结束，页数、耗时、补丁数量、文件大小。
- Warn：未映射标记、合同错误；阻止不完整映射的导出。
- Error：加载、解析、写回异常；同时显示 UI 错误，保留修改以便重试。
- 追踪与指标预留在加载/补丁/导出节点；首版不上传遥测。

## 首版限制

SVG 属于近似渲染：浏览器字体度量、图表坐标轴/样式和复杂特效尚未做像素一致验收。图表当前显示常见柱、折线、饼/圆环类型，原生数据保持只读。未支持类型会显示占位类型；不会把占位图写回 PPTX。

浏览器合同检查覆盖当前标记结构，完整模板发布仍需现有编译器校验。尚未完成真实 Microsoft PowerPoint 打开无修复提示的原生验收，不能据程序测试宣称全部 Office 环境通过。

### 渲染修正：第 17、18 页

从原始 OOXML 读取梯形 adj，使用短边和宽度上限计算路径，避免 parser 生成越界多边形。渐变 stop 的百分数字符串转换为 SVG 数值 offset；画布裁剪到幻灯片边界。已加入真实两页 10 个梯形的边界与渐变回归测试；这些适配只影响预览，不改原始 PPTX。

### 节点内容的写回

节点内容是模板的填充语义。文本节点提供纯文本编辑框，默认值去重但不自动覆盖原稿；用户修改才产生 text 补丁。写回保留 txBody 属性、首段 pPr 和首个 run 的 rPr，按新内容重建文本 run（混排收敛为首个 run 样式），支持换行与空内容。图表和表格数据不在此入口开放。字数预览独立于 text 补丁，导出重新读取并核对真实节点内容。

### 标记的添加与删除

“固定内容”是未标记状态，不是标记类型。已标记对象提供删除操作；删除只移除 DSL 名称，不删除 PPT 对象或内容。删除组合标记会同时清除其子对象标记。未标记对象可从画布或默认展示全部对象的列表选中，再添加标记。画布标记轮廓随补丁同步更新。文本对象只开放文本类（文本、序号），图片只开放图片类（图片、图标、页面级共享背景）；组合、原生表格和图表各自使用对应类型。类型判断基于 OOXML 能力，避免根据错误 AI 标签误判。校验层也拒绝跨类型标记，增删可撤销并写回 PPTX。

产品流程：未来上传后由后台 AI 先打标，用户以纠错、删除、补标为主；当前纯前端演示继续使用已有标记的极简商务，上传仍处于开发中。

### 布局操作入口

移除位置与大小的坐标表单，保留画布拖动及缩放。重置位置恢复当前对象的原始位置与大小，只清除其 box 补丁，保留标记和节点内容。重置所有操作恢复整个模板的标记、内容和布局，清除未应用的草稿及字数预览；该次重置仍可通过撤销恢复已提交的修改。中英文界面保持一致。

### 右侧工具栏与导出入口

操作（撤销、重做、重置位置、重置所有操作）移至画布上方，以带细边框的紧凑工具栏承载无底色文字按钮，横向排列。右侧保留对象列表与标记两个区域，对象列表固定在上方，标记区域独立滚动；移动端依次排列。顶部显示模板、页数与全页预览，右侧提供明确的“下一步”按钮；其与第 03 步共用导出确认弹框，不直接触发写回。第 01/02 步直接切换；加载模板后第 03 步可点击，先弹框确认，取消保留当前编辑状态；确认后应用当前节点草稿、校验并写回，成功后进入下载页。导出失败保留弹框与错误信息，完整保留修改供重试。

导出确认 dialog 显式使用 fixed / inset: 0 / margin: auto 在浏览器视口居中，并限制最大高度；不依赖被 Tailwind preflight 重置的浏览器默认 margin。

### 撤销与重做快捷键

工作台第 02 步：Mac 使用 ⌘Z 撤销、⇧⌘Z 重做；Windows 使用 Ctrl+Z 撤销、Ctrl+Y 重做，并兼容 Ctrl+Shift+Z。按钮 tooltip 和 aria-keyshortcuts 同步说明快捷键。输入框、富文本输入、IME 组合输入、打开的弹窗、导出和拖动期间不接管工作台历史快捷键；输入框保留原生文字撤销。

数字输入允许暂时清空以便重填；失焦时恢复最近的有效整数，不把空值、负数或小数写入范围。加减、直接输入与键盘上下箭头都沿用实时字数预览。

画布上方仅保留操作栏。页码、节点内容可编辑/实时预览提示及页面尺寸合并在画布底部状态栏；字数控件明确注明“预览效果不进入最终模板”，节点内容提示精简为“帮助 AI 理解此节点。”，中英文同步。

字数预览提示固定分为两行：有预览时第一行只显示预览字数，第二行独立提示预览效果不进入最终模板。

### 字数按钮长按调节

加减按钮单击保持 ±1；鼠标按住 350ms 后弹出纵向调节条，向上增加、向下减少，每 6px 对应 1 字，最小为 0，沿用实时画布预览。调节条通过 portal 放到 body，避免右侧滚动容器裁剪；松开后收起，不额外触发单击。指针取消或窗口失焦回到本次长按前的数值，组件卸载清理监听和光标状态。触屏单击及键盘操作保留原行为，中英文 tooltip 提示长按用法。

对象 ID 不在画布底部及对象列表中展示。内部 SourceNode.id、key、选择映射、日志及原 PPTX 定点写回完整保留。

画布与对象列表共用选中状态：点选画布对象时，右侧列表自动滚动使对应行可见并高亮；点选列表行时，画布显示对应对象的选中框与缩放手柄。滚动仅作用于列表，不移动页面；仅显示标记时仍保留当前选中的未标记对象。序号属性改为“序号格式 / Number format”下拉选择，以 `1 · 2 · 3`、`01 · 02 · 03`、`001 · 002 · 003` 等示例表达补零格式，保留原有 1–6 位 DSL 数据与写回规则。

### 列表分组与项数预览

- 从现有 DSL 派生列表与列表项，不改 SourceNode 或原始 PPTX 结构；兼容组合列表及散落节点固定列表。显示名称为列表 A/B 等，内部列表编号继续保留。
- Canvas 整体虚线框、列表项淡框和对象树左侧细线使用同一颜色；不同列表区分淡色，选中仍使用紫色。整体标签可点击选中控制节点，对象树按列表/项/节点折叠，双向选择时自动展开对应行。
- 选择列表内节点时显示列表设置。“允许 AI 调整项数”切换动态与固定，固定项数等于原始项数。动态规则只更新第一项 DSL，支持撤销/重做；上下限必须包含原始项数，以满足现有 DSL 编译合同。散落节点列表在启用动态项数时，按已有 DSL 成员关系将整份列表的各项转换为原生组合。
- 动态列表提供右侧及 Canvas 标签旁的减/加预览，按最少/最多钳制。减少时仅隐藏尾部项；增加时按原项位置的平均方向与间距延续，复用首项 SVG 并降低透明度，不叠加文字标签。首版不自动重排或压缩布局，超出页面的部分由 Canvas 裁剪。
- 项数预览使用独立内存状态，不进入 Patches、不增删 OOXML 对象、不影响导出项数；静态模式忽略该状态，重置所有操作清除它。显示层最多渲染前 100 项以控制浏览器开销，DSL 最大项数不受此显示上限影响。
- 新增 `lib/pptx/lists.ts`、`components/pptx/list-objects.tsx` 和 `components/pptx/list-settings.tsx`；所有新增操作与提示提供中英文。

列表树的“第 N 项”直接代表对应原生根组合，省略其下重复的 `@列表@项` 组合行；选中高亮、自动展开定位仍绑定同一个原始对象。内容节点照常展示，显示名称兼容 `@1@1 文本`、`@1@1 @文本[2-8]` 等前缀形式，只在 UI 中移除列表前缀及开头的 @。组内内容即使重复携带列表前缀，也不会被重复当作列表根；散落文本节点仍保留内容行。原始名称、内部 ID、DSL 校验与写回不变，不自动修复无效 DSL。


### 组合模式与真实 PPT 结构写回

- 用户确认“增减组合”指编辑现有列表项的组成员，不是改变真实列表项数。右侧列表设置提供“编辑组合成员”，进入后从 Canvas 选择对象加入组合，成员列表只展示已选对象，取消勾选立即从列表移除，之后可从 Canvas 重新选回；紫色淡框高亮已选成员，确认后作为一次可撤销补丁提交，取消无副作用。移出是解除成员关系，不删除对象。切页/撤销/重做/重置会退出模式；编辑期间不允许导出或拖动对象。
- 候选限于当前项直接成员和未归属其他列表项的页面对象；支持普通形状、文字、图片及独立组合，不开放跨列表项搬移、嵌套列表项编辑或原生图表/表格加入列表。拒绝空组合、不完整项序列、继承几何和无法无损表示的剪切变换，错误上报并保留草稿。
- 固定散落列表经确认成员编辑或启用动态项数，会将同一列表的每一项一起转换为原生 Group，避免 Group 与散落 DSL 混用。成员名称去除列表前缀，规范为组内组件 DSL；首组声明动态范围，后续组不重复范围。未标记装饰保持未标记。组件合同仍须通过校验，单独增加某一项的标记类型可能导致合同不一致，届时阻止导出并显示原因。
- `lib/pptx/grouping.ts` 为历史补丁新增 native-group 结构快照，记录成员/移出对象的页面空间几何。SVG 以派生模型展示，原始 ZIP 不变；原始对象 ID、文字、样式、媒体关系继续保留，新组合使用同页未占用 ID。重置恢复原始文件结构。
- 写回真实 `p:grpSp` / `p:nvGrpSpPr` / `p:grpSpPr`，移动原节点而非复制或删除内容；统一组变换与成员坐标，保留成员内部样式与嵌套组合的子坐标系。新组插入首个成员处，成员归为连续绘制单元，因此与组外对象交错的层叠顺序可能改变，这是原生组合的限制。首版不支持组层级的任意重排。
- 导出回读核对组合类型、成员 parentId 和移出后的页面层级。20 项测试覆盖新组合、已有组合修改、移出后坐标保持、原对象 ID/文本保持、其他 ZIP parts 字节不变；测试导出重新通过 PPT-DSL 编译，33 页/279 个标记组件、零错误和警告。尚未完成 Microsoft PowerPoint 实机打开验收。
- 项数增减仍是独立预览，不增删实际 Item；真实结构变化仅来自显式成员编辑或散落列表转原生组合。与之前“所有结构不变”的表述相比，这是本次用户明确要求开放的范围。

列表项级选择只展示列表设置和组合成员编辑，隐藏标记类型、增删标记、列表 ID、Item 序号及应用标记操作。原生组合项与散落列表的项标题统一处理；点击子内容节点时恢复节点标记编辑。仅调整 UI 的选择语义，内部列表/项编号、DSL 与 PPTX 数据完整保留。
