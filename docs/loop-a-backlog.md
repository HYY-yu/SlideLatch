# 循环 A 首轮队列

这是可派发的本地开发队列，不是已经创建的 GitHub Issue，也不代表后台工作常驻运行。编号仅是文档内的工作项 ID。

| 工作项 | Owner 角色 | 依赖 | 验收与状态 |
| --- | --- | --- | --- |
| A-001 团队与 CI 基础 | integration_manager | 本地融合基线 | 独立 worktree、角色/模板、完整 verify、当前 SHA 独立审查、GitHub 实际 CI；远端状态以 PR 为准 |
| A-002 模板合同回归边界 | template_contract | A-001 被用户接受 | 清点现有负例与支持矩阵，选一个真实缺口补回归；不扩大支持承诺 |
| A-003 编辑器状态与导出回归 | editor_workflow | A-001 被用户接受 | 导入失败、重复提案、撤销/重做、旧快照、下载重导入的真实浏览器检查 |
| A-004 原生保真验收基线 | native_fidelity | A-001 被用户接受，可用 PowerPoint 与授权样本 | 明确原生渲染环境，对现有授权样例建立页/对象对照，保留修复提示与字体问题 |

A-001 是当前配置任务。A-002 至 A-004 是后续开发建议，并非已执行或自动获准持续运行。首轮由 CI 实现 owner 和团队流程 owner 并行准备，随后由未参与实现的 verifier 检查集成 SHA。

循环 B 暂停。先确定足量、合法、可用于测试且不含客户隐私的 PPT 来源，再设计覆盖矩阵。不得为填充数量自动下载、上传或发布第三方 PPT，也不能把 demo 通过当作普遍能力证明。
