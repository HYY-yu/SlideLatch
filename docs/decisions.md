# 产品决策

更新：2026-10-31。

## 已定方向

| 事项 | 决定 |
| --- | --- |
| 名称 | SlideLatch |
| 中文文案 | 配置一次 PPT 模板，让 AI 按你的设计生成。 |
| 英文文案 | Your PowerPoint design. Reused by AI. |
| 产品方向 | 在已有 PPT 上辅助打标，首次确认配置，后续复用合同生成可编辑 PPTX |
| AI 接入 | 外部 AI 生成标准内容，由确定性生成器校验与填充 |
| 项目边界 | 独立于 OpportunityRadar，资料集中在当前目录 |
| Landing | 采用 Cruip Open，首版保持精简，支持中英文 |
| 编辑边界 | 可修改节点语义内容、标记、元素位置和尺寸；样式只读 |
| 渲染与写回 | pptxtojson + 自建 SVG；保留原 PPTX，按对象 ID 写回补丁，纯前端执行 |

## 待定方案

| 方案 | 判断依据 |
| --- | --- |
| 先招募、演示与人工试点，再收敛 MVP | 获取真实模板、重复使用和购买证据 |
| 首批面向小型咨询、研究及报告交付团队 | 稳定设计和重复交付有望摊薄配置成本 |
| 本地单用户网页工作台 | 文件处理与任务保存在用户设备，降低首版复杂度 |
| 动态文本、图片、固定及有界变长列表优先 | 由真实模板覆盖率决定是否扩大组件范围 |
| 先按模板接入收费 | 验证配置成本与付费意愿，价格通过试点确定 |

## 产品约束

- 同一模板版本复用配置；设计、节点或合同变化后发布新版本。
- 输入合同约束字段、长度和容量，最终文件仍需视觉与 PowerPoint 原生验收。
- 潜在差异是原对象打标、可定位的约束、可迁移合同和独立生成；Slideform 等已覆盖自动模板化与外部 API 填充。

功能范围见 [MVP 需求](mvp-requirements.md)，实验安排见 [用户验证](validation-plan.md)，品牌核查见 [品牌与域名](naming-and-domains.md)。

- 模板上传后的目标流程为后台 AI 初次打标，用户审核、换标、删标和补标；未标记内容不允许 AI 填充。当前演示保留纯前端与现有已打标模板。
