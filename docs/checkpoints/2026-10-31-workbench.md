# 工作台阶段存档 · 2026-10-31

本轮完成中英文 landing 与极简商务 33 页纯前端 PPTX 工作台。

- 33 页缩略图、SVG Canvas、对象列表双向选中和定位；用户界面隐藏对象 ID，内部定位保留。
- DSL 标记增删、兼容类型切换、可编辑节点内容；文本长度数字步进、长按纵向调节与独立字数预览。
- Canvas 拖动/缩放、重置位置/全部操作、撤销/重做及常用快捷键。
- 列表淡色分组、可折叠对象树、项级显示去重与非标准前缀兼容；序号格式以连续示例选择。
- 动态/固定列表切换、范围设置及独立项数预览；增加的预览项半透明显示，不覆盖“预览”文字。
- 组合模式支持加入/移出现有对象，只展示已选成员，取消勾选立即移出，可从 Canvas 选回。确认后可撤销，导出落为原生 PPT Group。
- 列表项本身不开放标记类型、列表 ID 或 Item 序号编辑；子节点标记编辑保留。
- 列表设置使用浅绿色完整边框。提示文案为“项数预览不进入最终模版”和“最少不能大于 N，最多不能小于 N”。
- 第 03 步及下一步共用居中的导出确认弹框，浏览器本地校验、写回与下载，无后端。

验收：TypeScript 类型检查、20 项自动测试；浏览器验证成员移出/选回、列表项与子节点编辑区分、组合导出。原生组合测试产物经 PPT-DSL 编译为 33 页、279 个标记组件，零错误、零警告。

边界：SVG 仍为近似渲染；尚未完成真实 Microsoft PowerPoint 打开验收。组合需遵守组件合同，复杂剪切变换等会明确拒绝；原生组合可能改变与组外对象交错的绘制层级。项数预览不增删真实 Item。

详细设计见 ../design/pptx-workbench.md。阶段源码与资源压缩包保存在 backups（本地存档，不纳入 Git），依赖由 package-lock.json 恢复。项目仓库为 https://github.com/HYY-yu/SlideLatch，默认分支 main。
