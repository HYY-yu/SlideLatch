# F09 点赞、反馈与试用申请

用户在案例区点赞，响应调查邀请，或从导航、案例区和页尾打开试用申请。表单加载失败时可重试或直达 Tally。

## Sub-features

- F09.1 点赞计数、当前标签会话保持、调查邀请及关闭。
- F09.2 多个试用入口、中英文表单。
- F09.3 加载失败提示、重试和外部表单直达。

## How to get to it (user POV)

`#results` 的 **支持一下 / Send some love**，导航、案例区和页尾的 **申请试用 / Apply for early access**，以及调查邀请的 **愿意 / Sure**。同名按钮按区域定位。

## Driving it with CUA

Preconditions: 新专用标签，基线不配置 PostHog。普通验证只操作本地点赞和关闭邀请。打开外部 Tally 或提交答案需要当前授权；没有授权时保留相关入口 not_run。

- 点赞：读取 `#support-count`，待按钮启用后点击当前 DOM 中「支持一下」按钮。观察计数加一和按钮状态，再刷新本次标签，观察 sessionStorage 中计数保留。不要影响用户已有标签。
- 邀请：在本次标签累计点赞 4 次，观察调查邀请，记录实际次数及邀请文字。点击 **暂时不了 / Not now**，观察邀请消失并保留点赞。不得为了通过去修改 sessionStorage 或内部状态。
- 表单入口：有打开表单授权时，分别从导航、案例、页尾及调查接受入口点击当前 locale 的申请按钮，观察表单 ID、语言和来源对应。每次关闭后再测下一入口。
- 加载恢复：只有真实加载失败时，观察错误 dialog、**重试 / Try again** 和 **直接打开表单 / Open the form directly** 链接，再按已授权路径验证恢复。不能把正常打开冒充错误恢复，也不擅自切断用户网络制造失败。
- 提交：仅当明确授权测试提交、测试数据及目的地时填写并提交；检查 Tally 确认页面及真实副作用，不能仅凭按钮点击认定提交成功。默认不执行。

## Gotchas

- 按钮英文和邀请阈值以当前界面及规则为准，发现漂移更新地图；不要硬编码旧 AX 索引。
- 试用表单是外部服务，表单答案不能写入 PostHog。未配置分析不证明所有第三方网络流量为零。
- 关闭本次标签即释放本次 sessionStorage；清理不删除用户浏览器数据。
