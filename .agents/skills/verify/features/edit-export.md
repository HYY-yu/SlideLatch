# F03 配置与导出模板

用户选择 PPT 原对象，修改标记、节点文字、位置或列表设置，并导出写回后的 PPTX。

## Sub-features

- F03.1 画布和对象列表选择、仅显示标记。
- F03.2 标记类型、文本字数、序号格式、节点内容。
- F03.3 位置尺寸、列表与组合、预览。
- F03.4 撤销、重做、重置、导出与重新导入。

## How to get to it (user POV)

F02 打开模板后进入 **调整区域 / Configure regions**。选择画布对象或对象列表，右侧出现属性。工具栏提供 **撤销 / Undo**、**重做 / Redo** 和重置。**下一步 / Next step** 打开导出确认框。

## Driving it with CUA

Preconditions: 加载公开 33 页中文模板。每个子路径独立从未修改模板开始。使用当前对象列表中真实可选的文本对象，记录它的名称及页面，不能按对象在列表中的次序定位。

- 文字：选择有「节点内容 / Node content」的文本对象，记录原值。用 label 填入与原合同长度相符的合成文字，点击 **应用标记 / Apply tag** 或离开字段触发保存。观察画布及字段更新。
- 历史：点击 **撤销**，重新读取文字为原值；点击 **重做**，文字恢复修改。保存三种状态。点击 **重置所有操作 / Reset all changes** 后观察初值和修改数。
- 标记：切换「仅显示标记」，观察对象列表变化；对可编辑类型执行删除/添加标记并检查属性。修改文本的 **最少 / Minimum** 超过原最多值，观察最多值随之抬高；将最多值调低到原最少值以下，观察最少值联动降低。负数、非整数或空输入不提交，失焦后恢复有效值。序号对象可用 **序号格式 / Number format** 改位数，观察合同及预览。
- 布局：选择有实际几何的可移动对象，保存截图，从当前截图读取选中框位置，用 CUA 的 `drag` 移动框体，再观察位置变化；拖动可见缩放手柄检查尺寸。点击 **重置位置 / Reset position**，观察恢复。当前没有坐标输入框；继承位置对象不能当作正例。
- 列表：选择已标记列表，在 **列表设置 / List settings** 中切换 **允许 AI 调整项数 / Allow AI to change item count**，操作最少/最多项数及 **预览项数 / Preview items**。点击 **编辑组合成员 / Edit group members**，改变成员后取消，观察未提交；再次进入并 **确认组合 / Confirm group** 后观察成员归属。记录所选列表及原数量，不假定所有页均有列表。列表 ID 和 Item 序号不是当前可编辑输入框。
- 导出：点击 **下一步**，在确认框点击 **继续调整 / Keep editing**，观察修改保留；再次打开并点 **确认并导出 / Confirm and export**。等待 **模板已写回 / Template exported**，注册 download 后点击 **下载修改后的模板 / Download modified template**。
- 重导入：保存下载文件和 SHA；通过 F02 的本地选择入口重新导入。检查修改对象文字、标记或位置与导出前一致。用 OOXML 结构检查补充证据，受影响视觉另做原生 PowerPoint 检查。

## Gotchas

- 缺少可编辑位置或组合的样本时该子功能 blocked，不能拿普通文字代替。
- 预览字数和列表数量不应成为最终正文。导出后应核对实际内容。
- 页面刷新不保留编辑状态。源码测试或导出提示不能代替落盘和重导入。
